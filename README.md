# Retail Sales Performance Dashboard

## Project Overview
Interactive Power BI dashboard built to track regional sales performance, 
profit margins and product trends for a fictional retail store chain 
across 4 regions and 50 products.

## Dashboard Pages
- **Sales Overview** — KPI cards, monthly sales trend, sales by region
- **Product Analysis** — Top categories, profit margins, best sellers
- **Customer Insights** — Sales by gender, age group, payment method
- **Trends & Growth** — Year-over-year comparison, YTD sales, rolling averages

## Key DAX Measures Built
- Total Sales, Total Profit, Profit Margin %
- Year-over-Year Growth %
- Year-to-Date Sales
- Sales Last Year (time intelligence)

## Skills Demonstrated
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Data modelling (star schema)
- Time intelligence functions
- Interactive drill-through and bookmarks

## Data
Synthetic retail dataset — 5,000 transactions across 200 customers, 
50 products and 5 store locations (2023–2024).
